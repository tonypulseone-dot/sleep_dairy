# Дневник сна и кабинет консультанта

Telegram Mini App для мамы + веб-кабинет для консультанта по детскому сну.

Мама ведёт дневник в один тап, консультант читает готовую таблицу и не считает
средние руками. Маме бесплатно всегда, платит консультант.

## Стек

- Next.js 16 (App Router) + TypeScript — одна кодовая база на Mini App и кабинет
- PostgreSQL + Drizzle ORM
- `@telegram-apps/sdk-react` — вход мамы без регистрации, по подписанному `initData`
- Кабинет консультанта — обычный веб-вход, открывается с компьютера и планшета

## Запуск

```bash
cp .env.example .env.local     # заполнить TELEGRAM_BOT_TOKEN
npm install
npm run db:migrate
npm run dev
```

Тесты доменной логики:

```bash
npm test
```

## Решения, зашитые в код

Всё ниже — не абстракции, а прямые требования с двух встреч с Викторией,
практикующим консультантом по сну. Менять их можно, но осознанно.

### Сонные сутки вместо календарных

Календарная полночь для дневника сна не годится: ребёнка уложили в 00:30 —
и ночной сон уезжает в следующий день, а суточный сон за вчера выглядит
катастрофой. Поэтому сутки режутся по границе, которую мама выставляет сама:

- `children.day_boundary_minutes` — во сколько начинается утро (по умолчанию 06:00)
- `children.night_from_minutes` — во сколько начинается ночь (по умолчанию 19:00)

Сон всегда относится к тем суткам, в которые он **начался**. Логика и её
разбор — в `src/lib/sleep-day.ts`, проверена тестами на реальных примерах,
включая часовые пояса.

### Чего в продукте нет намеренно

- **Ночные пробуждения не фиксируются.** «Я не рекомендую мамам ночью брать
  телефон. Лучше спите, а утром скажете». Это метод консультанта, а не пробел.
- **Подгузники, вес и прочие двадцать категорий** — то, из-за чего конкуренты
  превращаются в «1700 кнопок».
- **Кормление — только на искусственном и смешанном.** Грудное не отмечается.
- **Интервалы снов в таблице консультанта не выводятся** — только длительности.
- **Нормы не навязываются.** Ориентир по режиму считается по данным самого
  ребёнка, таблица норм — запасной вариант на первые дни, показывается
  диапазоном и выключается в настройках (`children.show_rhythm_hint`).

### Доступ к данным

Мама явной галочкой даёт доступ конкретному консультанту и отзывает его в один
тап (`access_grants`, с версией текста согласия). Консультация закончилась —
доступ закрыт, дневник остаётся у мамы навсегда.

## Структура

```
src/

  lib/sleep-day.ts    сонные сутки, классификация снов, итоги и средние

```
